첫 화면 / 페이지 설정

첫 화면 문구/안내 문구/버튼 문구는 입력 후 다른 곳을 클릭하면 자동 저장됩니다.

첫 화면 이미지는 선택 후 업로드가 끝나면 자동 저장됩니다.

첫 화면의 이름과 한마디는 CHARACTER 메뉴의 ‘캐릭터 이름’과 ‘한 줄 문구’를 그대로 사용합니다.

데이터 주의

관리자 페이지는 비밀번호를 코드에 저장하지 않습니다. Supabase Auth 세션과 RLS가 실제 수정 권한을 판단합니다.

프로젝트의 service_role 키는 절대로 config.js에 넣지 마세요.
